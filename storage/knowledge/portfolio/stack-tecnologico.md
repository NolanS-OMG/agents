# Stack Tecnológico

## Lenguajes de Programación

- **JavaScript (ES6+)**: Desarrollo frontend y backend moderno
- **TypeScript**: Tipado estático para aplicaciones escalables
- **Python**: IA/ML, backend, automatización
- **Ruby**: Desarrollo web con Ruby on Rails
- **Java**: Aplicaciones empresariales con Spring Boot
- **Apex**: Desarrollo en ecosistema Salesforce

## Inteligencia Artificial & Datos

- **Sistemas Multi-Agente**: Diseño y orquestación de agentes autónomos
- **RAG (Retrieval-Augmented Generation)**: Implementación de sistemas de conocimiento aumentado
- **Prompt Engineering**: Optimización de interacciones con LLMs
- **PyTorch**: Deep Learning y redes neuronales
- **TensorFlow**: Machine Learning y modelos de IA
- **NumPy & Pandas**: Análisis y procesamiento de datos
- **Gymnasium / Gym**: Entrenamiento de agentes con Reinforcement Learning
- **Stable-Baselines3**: Algoritmos de RL (PPO, DQN, etc.)
- **ONNX Runtime**: Inferencia de modelos en navegador

## Frontend

- **React**: Desarrollo de aplicaciones web modernas
- **Next.js**: Framework React con SSR y optimización
- **Tailwind CSS**: Diseño responsive y utility-first
- **HTML5 & CSS3**: Fundamentos web sólidos
- **Lightning Web Components (LWC)**: Desarrollo en Salesforce

## Backend & APIs

- **Node.js**: Runtime JavaScript para backend
- **Ruby on Rails**: Framework MVC completo
- **Spring Boot**: Aplicaciones empresariales Java
- **FastAPI**: APIs de alto rendimiento en Python
- **REST API Architecture**: Diseño de APIs RESTful
- **Firebase**: Backend-as-a-Service (Authentication, Firestore)

## Bases de Datos

- **PostgreSQL**: Base de datos relacional avanzada
- **MongoDB**: Base de datos NoSQL orientada a documentos
- **MySQL**: Sistema de gestión de bases de datos relacional
- **Firestore**: Base de datos NoSQL en tiempo real de Firebase
- **Redis**: Cache y almacenamiento en memoria

## Cloud & DevOps

- **AWS (Amazon Web Services)**:
  - Lambda: Funciones serverless
  - Bedrock: Servicios de IA generativa
  - S3: Almacenamiento de objetos
  - EC2: Servidores virtuales
- **Docker**: Contenedorización de aplicaciones
- **Jenkins**: Automatización de CI/CD
- **Git**: Control de versiones
- **CI/CD Pipelines**: Integración y despliegue continuo
- **Netlify**: Despliegue de aplicaciones frontend

## Herramientas & Metodologías

- **Control de Acceso Basado en Roles (RBAC)**: Implementación de permisos segmentados
- **Arquitectura Desacoplada**: Separación frontend/backend
- **Optimización de Performance**: Reducción de latencia y tiempos de carga
- **Salesforce CRM**: Desarrollo y personalización de flujos de trabajo

## Áreas de Especialización

- Sistemas de IA conversacional y multi-agente
- Arquitecturas RAG para chatbots inteligentes
- Optimización de rendimiento y escalabilidad
- Desarrollo full-stack con foco en IA
- Automatización de procesos empresariales
